# 프론트엔드 — 생성 전

이 폴더는 팀 화면개발용 예약 위치입니다. **현재 React/Vite 앱이나 `package.json`이 없습니다.**
화면설계서의 팀 승인과 실제 프론트엔드 담당자 확정 후 생성하세요.

제안 기술 (미확정): React + Vite + TypeScript.
API 기본 주소 (로컬): `http://localhost:8000`.
**확정된 API**는 `POST /api/contracts/extract-text`, `GET /health` 뿐입니다.
나머지는 `docs/API_CONTRACT_DRAFT.md`에서 제안 형식으로 관리합니다.

프론트엔드 의존성을 설치할 때는 `node_modules/`를 Git에 올리지 않습니다.
