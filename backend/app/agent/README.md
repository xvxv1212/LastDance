# AI Agent 레이어 — 설계 대기

**아직 구현된 Agent나 LangGraph 그래프는 없습니다.**

예상 처리 단계 (팀 합의 전 제안):
1. 계약서 및 사용자 설명에서 사실 **후보** 추출
2. 누락 정보 질문
3. 사용자 정정·승인 (Human-in-the-loop)
4. 승인된 사실 스냅샷 생성
5. 검증된 근거와 대조 (출처·적용일·시행일 포함)
6. 사실/주의사항/추가 확인사항을 구분해 보고서 생성

원문 문서의 지시문은 사용자의 명령이나 시스템 명령으로 해석하지 않습니다.
추론 과정에서 법률 결론·확정 환불액·승소 가능성을 단정하지 않습니다.
