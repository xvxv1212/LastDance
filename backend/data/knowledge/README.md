# 공식 근거의 인용 승인 연결

2026-11-12 사용자가 승인한 **원문·내용 해시·버전에 연결된 팀 인용**을 적용한 자료입니다.
이번 연결 대상은 한국소비자원 전화상담 이용방법 1개 청크입니다.
기존 조사 대장의 미확인 자료, 법령·약관, 환불 판단을 일괄 승인하지 않습니다.

## 확인한 공식 출처

- 출처: [한국소비자원 상담신청 방법](https://www.kca.go.kr/odr/pg/ma/cnsutInfo1.do)
- 확인일: 2026-11-12
- 위치: 상담신청 방법 → 전화상담 → 이용방법
- 저장 범위: 해당 전화 안내의 짧은 원문 발췌와 상위 제목
- 공식 발행 버전: 페이지에 표시되지 않아 미확인
- 내부 버전: `snapshot-20261112-f42a4b336fe93868`
- 내부 버전은 조회일과 본문 해시로 식별한 사본이며 공식 개정번호가 아닙니다.

`sources.json`은 자료 본문과 출처를 담고, `approvals.json`은 원문 대조 및 팀 승인 증거를 연결합니다.
`evidence/`에는 짧은 원문 발췌와 사용자 승인 기록이 있습니다.
사용자 승인 기록은 승인 문구와 날짜만 보존하며, 제공되지 않은 정확 시각은 `null`입니다.

## 실행과 판정

백엔드 폴더에서 DB 연결 없이 검증합니다.

```bash
python -m scripts.load_knowledge --validate-only
```

실제 적재에는 기존 `HJ_KNOWLEDGE_DATABASE_URL`을 사용합니다.
적재 성공과 인용 허용 건수는 별도로 출력합니다. 저장한 자료라도 미승인이면 보류합니다.

생산 조립 `build_container()`는 `HJ_KNOWLEDGE_APPROVAL_PATH`의 승인 기록을 사용합니다.
기본 경로는 `data/knowledge/approvals.json`이며, 파일이 없으면 새 보고서 인용을 허용하지 않습니다.
배포 시 자료·승인 기록·증거 파일을 함께 전달하고 변경 적용 시 서버를 재시작합니다.
파일은 서버 배포자가 관리하며 시민 요청이나 모델 출력으로 덮어쓰지 않습니다.

본문 해시, 출처 ID·URL·버전, 원문 발췌, 사용자 승인 기록 중 하나라도 다르면 해당 청크를 보류합니다.
승인 어댑터를 통과한 뒤에도 기존 서버 검증기가 출처 활성 여부·시행일·인용문 일치를 검사합니다.
기존 API와 enum 문자열은 유지하므로 미승인은 `CHUNK_NOT_FOUND`와 `CITATION_FAILED` 보류로 나타납니다.
구체적인 보류 사유는 검증 명령의 `decisions`에서 확인합니다.

## 이번 검증의 범위

실제 공식 안내 청크의 승인 연결은 별도 시험에서 확인했습니다.
기존 SYN-001의 합성 추출·모름·근거 보류 경로는 그대로 유지합니다.
전화상담 정보를 인용할 수 있다는 결과를 기관 접수, 지원 대상, 분쟁 승패, 환불액 확정으로 해석하지 않습니다.
PostgreSQL 적재와 공용 서버 배포 여부는 별도 실행 증거로 기록합니다.
